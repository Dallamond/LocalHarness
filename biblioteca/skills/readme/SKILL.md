Un buen README responde en este orden:
1. Qué es y para qué sirve (2-3 frases).
2. Requisitos (versiones) e instalación paso a paso, con órdenes copiables. Si hay diferencias Windows/Linux, ambas.
3. Uso mínimo: el ejemplo más corto que funciona, con su salida.
4. Configuración: variables de entorno y archivos, con valores por defecto.
5. Cómo ejecutar los tests y cómo contribuir.
Comprueba que cada orden del README funciona de verdad en el repo. No prometas funciones que no existen.
