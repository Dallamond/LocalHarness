- Sección «Sin publicar» arriba; al publicar, pasa a «## [versión] - AAAA-MM-DD».
- Grupos: Añadido, Cambiado, Obsoleto, Eliminado, Arreglado, Seguridad.
- Cada entrada desde el punto de vista del usuario («Ahora se puede exportar a CSV»), no del código.
- Cambios incompatibles, marcados y con cómo migrar.
- Una entrada por cambio relevante; nada de copiar el git log.
