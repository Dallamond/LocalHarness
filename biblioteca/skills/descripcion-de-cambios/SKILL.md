name: descripcion-de-cambios
description: Resumen final de una tarea o PR: qué cambia, por qué, cómo se ha probado y riesgos
category: Git
tags: pr resumen informe
---

Al terminar una tarea, entrega un resumen con estas secciones (cortas):
- **Qué cambia**: 2-5 viñetas con lo visible para el usuario o el sistema.
- **Por qué**: el problema o la petición.
- **Cómo se ha probado**: órdenes ejecutadas y resultado (número de tests, prueba manual).
- **Riesgos / pendiente**: lo que podría romperse, lo que no has podido probar, decisiones a confirmar.
Sin relleno ni repetir el diff línea a línea. Si algo no se pudo hacer, dilo claramente.
