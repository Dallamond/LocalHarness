---
name: tests-primero
description: Para arreglar un fallo o añadir una función: primero un test que lo demuestre, luego el código
category: Calidad y tests
---

1. Antes de tocar el código, escribe (o amplía) un test que reproduzca el fallo o describa la función nueva.
   Usa el framework que ya tenga el proyecto; si no hay ninguno y es Python, `unittest` de la biblioteca estándar.
2. Haz el cambio mínimo en el código para que ese test pase.
3. No borres ni debilites tests existentes para que pasen.
4. En tu respuesta final indica qué test añadiste y qué comprueba.
